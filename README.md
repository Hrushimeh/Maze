# Maze

Hello! Welcome to the Maze repository.

## Description

This repository contains a Java-based 2D maze application with a graphical user interface. The application allows users to generate random mazes, read mazes from files, and find the shortest path through the maze using pathfinding algorithms.

## Getting Started

To get started with this project, you'll need:

- Java Development Kit (JDK) installed on your system
- A Java IDE or text editor
- Basic understanding of Java programming

### Running the Application

1. Compile the Java source file
2. Run the Maze class to launch the GUI
3. Choose between generating a maze or reading from a file
4. Explore the maze and find the shortest path

For more detailed information, please refer to the source code documentation.
