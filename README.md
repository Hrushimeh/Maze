# Maze

Hello and welcome to the Maze repository! 👋

## Description

This repository contains a Java-based 2D maze application with a graphical user interface (GUI). The application allows users to generate random mazes or load mazes from files, and provides functionality to find the shortest path through the maze. It features both guaranteed path mazes and random mazes, with visual representations and path-finding algorithms.

## Getting Started

To get started with this project, you'll need:

- Java Development Kit (JDK) installed on your system
- A Java IDE or text editor for viewing and modifying the code
- Basic understanding of Java and Swing for GUI applications

### Running the Application

1. Clone or download this repository
2. Compile the Java source file: `javac Maze.java`
3. Run the application: `java Maze`
4. Choose between generating a random maze or reading from a file
5. Follow the on-screen instructions to interact with the maze

## Features

- Interactive GUI using Java Swing
- Generate random mazes with customizable dimensions (3-30 rows and columns)
- Load mazes from external files
- Find and display the shortest path through the maze
- Visual representation of maze elements (walls, open spaces, start, and exit)
